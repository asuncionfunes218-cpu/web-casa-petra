# web-casa-petra
Realizador de paginas web profesionales

## Tortillerxs

Sitio web estático (HTML/CSS/JS, sin build) para **Tortillerxs**, bar de tapas &amp; take away en el Casco Antiguo de Sevilla.

### Estructura

- `index.html` — página única con Inicio, Nosotros, Carta, Galería, Ubicaciones y Contacto
- `css/style.css` — estilos
- `js/script.js` — menú móvil, acordeón de la carta, año dinámico del footer
- `assets/img/` — fotografía real del local, mural y platos

### Desarrollo local

No requiere instalación. Basta con abrir `index.html` en el navegador o servir la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```
